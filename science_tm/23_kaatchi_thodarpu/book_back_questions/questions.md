### I. சரியான விடையைத் தேர்ந்தெடுத்து எழுதுக

1. அசைவூட்டும் காணொளிகளை உருவாக்கப் பயன்படும் மென்பொருள் எது?  
   அ) Paint  
   ஆ) PDF  
   இ) MS Word  
   ஈ) Scratch  

2. பல கோப்புகள் சேமிக்கப்படும் இடம்:  
   அ) கோப்புத் தொகுப்பு (Folder)  
   ஆ) பெட்டி  
   இ) Paint  
   ஈ) ஸ்கேனர்  

3. நிரல் (Script) உருவாக்கப் பயன்படுவது எது?  
   அ) Script area  
   ஆ) Block palette  
   இ) Stage  
   ஈ) Sprite  

4. நிரலாக்கத்தைத் தொகுக்கப் பயன்படுவது எது?  
   அ) Inkscape  
   ஆ) Script editor  
   இ) Stage  
   ஈ) Sprite  

5. பிளாக்குகளை (Block) உருவாக்கப் பயன்படுவது எது?  
   அ) Block palette  
   ஆ) Block menu  
   இ) Script area  
   ஈ) Sprite
